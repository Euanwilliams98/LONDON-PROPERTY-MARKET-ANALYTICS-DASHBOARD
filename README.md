
# 🏠 LONDON-PROPERTY-MARKET-ANALYTICS-DASHBOARD

## 🔍 Overview

This project was completed as part of my Data Analytics portfolio and focuses on analysing UK residential property data using SQL and Power BI. The objective was to transform raw property and transaction datasets into an interactive business intelligence dashboard that provides insights into property prices, market value, housing trends, and new build activity.

The project combines data cleaning, SQL analysis, data modelling, DAX calculations, and dashboard design to support data-driven decision-making within the property sector.

---

## 🚀 Skills Demonstrated

### ✔️ Data Cleaning & Preparation (SQL & Excel)

* Importing and preparing large property datasets for analysis
* Cleaning price fields by removing currency symbols and formatting inconsistencies
* Validating data quality and checking for missing values
* Identifying duplicate records and ensuring data integrity
* Converting data into analysis-ready formats
* Preparing datasets for reporting and visualisation

### ✔️ SQL Analysis

* Writing aggregation queries to analyse property market trends
* Calculating average, median, and total market values
* Using filtering and grouping techniques to segment property data
* Exploring relationships between property characteristics and pricing
* Performing historical transaction analysis across 30 years of data

### ✔️ Data Modelling & DAX

* Creating relationships between property and transaction datasets
* Building a structured data model within Power BI
* Developing DAX measures for key business metrics
* Calculating market value, average property prices, median prices, and property counts
* Generating performance indicators to support business analysis

### ✔️ Data Visualisation

Designing clear and impactful visualisations including:

* KPI Scorecards
* Bar Charts
* Column Charts
* Line Charts
* Donut Charts

Applying consistent formatting and dashboard design principles to improve readability and user experience.

### ✔️ Interactive Reporting

* Implementing interactive filters and slicers
* Creating dynamic visualisations for user exploration
* Enabling stakeholders to investigate property market trends
* Supporting drill-down analysis through interactive dashboards

### ✔️ Dashboard Design

* Building a professional executive-style dashboard
* Structuring reports around key business questions
* Highlighting important market trends and insights
* Creating a layout suitable for business stakeholders and decision-makers

## 📊 Key Findings
*The dataset contains 22,258 properties with a total market value of around £15.7 billion

*The average property price is £704K, while the typical property median price is £430K. This suggests there are some very expensive properties that push the average price up. 

*Flats are the most common property type and make up the largest share of properties in the dataset

*Detached homes have the highest average price, at around £947K.

*New build properties make up 11% of all listings, with 2,458 new build homes in the dataset.

*Flats contribute the most to the overall market value, with a combined value of around £9.8 billion.

*Looking at the historical sales data, property prices have generally increased over time.
